# Linux Files and Directory Hierarchy

## Question

What is Linux Files and Directory Hierarchy and why is it used?

## Short Answer

In Linux and Unix-like operating systems, the filesystem is structured as a unified single inverted tree originating from the root directory represented by a forward slash `/`. There are no separate drive letters like `C:` or `D:`; all storage devices and partitions are mounted as branches within this single directory tree. Standard directories such as `/bin`, `/etc`, `/home`, and `/var` serve designated system purposes.

## Simple Example

`/home/alice/projects/server.py` defines an absolute path starting at the root directory `/` and traversing down the hierarchy.

## Key Point

Linux organizes all storage into a single inverted directory hierarchy starting from the root directory `/`.
