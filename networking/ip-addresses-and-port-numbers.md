# IP Addresses and Port Numbers

## Question

How do IP Addresses and Port Numbers work at a basic level?

## Short Answer

An IP address uniquely identifies a device connected to a computer network, allowing packets to be routed across the Internet. A port number is a 16-bit integer that designates a specific application or service running on that host machine. While the IP address delivers data packets to the correct physical computer, the port number directs traffic to the correct software process.

## Simple Example

Connecting to `192.168.1.10:443` routes traffic to host `192.168.1.10` and specifically delivers it to the HTTPS web server listening on port `443`.

## Key Point

IP addresses locate the computer host on a network, while port numbers locate the target program on that host.
