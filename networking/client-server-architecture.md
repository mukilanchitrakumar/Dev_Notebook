# Client-Server Architecture

## Question

What is client-server architecture and why is it fundamental?

## Short Answer

The client-server architecture is a distributed computing structure that partitions workloads between service providers (servers) and service requesters (clients). A client initiates requests over a computer network to ask for data or operations, while the server listens passively for incoming requests, processes them, and returns responses. This separation allows servers to centralize data management, security, and business logic.

## Simple Example

A web browser (client) sends an HTTP GET request to `api.example.com`. The web server receives the request, queries its database, and responds with a JSON payload.

## Key Point

Clients request resources and servers fulfill them, decoupling user interface from core data processing.
