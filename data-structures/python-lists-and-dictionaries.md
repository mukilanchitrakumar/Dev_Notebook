# Python Lists and Dictionaries

## Question

Why are Python Lists and Dictionaries important in software engineering?

## Short Answer

Lists and dictionaries are Python's two most fundamental collection types for organizing multiple data items. A list is an ordered, mutable sequence indexed by integer positions starting at zero, while a dictionary stores unordered key-value pairs accessed via unique immutable keys. Both structures allow adding, updating, and removing items dynamically during program execution.

## Simple Example

```python
# Ordered list
ports = [80, 443, 8080]
# Key-value dictionary
service = {'name': 'web', 'port': 443, 'ssl': True}
```

## Key Point

Use lists for ordered sequences of elements, and use dictionaries for fast lookups by key.
