## Note Structure

Each topic note contains:

1. **Question**: The core technical mechanism or problem.
2. **Short Answer**: Concise 2–5 sentence direct explanation.
3. **Simple Example**: A minimal code snippet, terminal command, or diagram.
4. **Key Point**: The primary takeaway to remember.
