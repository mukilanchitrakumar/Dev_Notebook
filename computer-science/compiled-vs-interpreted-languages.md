# Compiled vs Interpreted Languages

## Question

What is the difference between Compiled vs Interpreted Languages?

## Short Answer

Compiled languages translate high-level source code into native machine code files before runtime, delivering high execution speed and upfront type checking. Interpreted languages read and execute source instructions line-by-line or through an intermediate bytecode virtual machine at runtime, offering rapid development and portability across operating systems. Many modern environments employ Just-In-Time (JIT) compilation to combine the flexibility of interpretation with near-compiled speeds.

## Simple Example

C code is compiled directly into a native platform binary (`gcc main.c -o app`), whereas Python compiles code to `.pyc` bytecode executed inside the Python virtual machine.

## Key Point

Compilers translate code ahead of time into machine instructions, while interpreters execute instructions dynamically at runtime.
