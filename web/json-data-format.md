# JSON Data Format

## Question

What is JSON Data Format in Web?

## Short Answer

JavaScript Object Notation (JSON) is a lightweight, text-based data interchange format that is easy for humans to read and write and simple for machines to parse and generate. JSON represents structured data using two basic universal data structures: collections of key-value pairs (objects) and ordered lists of values (arrays). Because it is language-agnostic, JSON is the dominant data standard for web APIs.

## Simple Example

```json
{
  "status": "success",
  "userId": 101,
  "roles": ["admin", "editor"]
}
```

## Key Point

JSON provides a standardized, language-agnostic text format for transmitting structured data over networks.
